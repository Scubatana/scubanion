1 · Le projet

Comment ça marche

1

Le téléphone

Son podomètre compte les pas, sans matériel en plus. Ils font gagner de l'XP au compagnon.

2

Les quêtes

Géolocalisées, elles envoient le joueur vers des lieux réels : parcs, points d'intérêt.

3

Les rencontres

Deux joueurs se croisent : bonus pour leurs compagnons (BLE, recoupé par le serveur).

4

Les bornes IoT

Lecteur NFC + écran chez des partenaires : skins, événements, énigmes.

Exemple de collab : une borne au Decathlon de Châtelet-les-Halles qui débloque un skin exclusif.

Chaque choix est motivé

App mobile

Nuxt 4, Vue 3, TypeScript, Capacitor 8. Une base web, BLE et podomètre par plugin.

Socle posé

API et données

PHP 8.3, Laravel 13, MariaDB 11.4. Données très relationnelles.

Squelette

Borne

ESP32, Arduino ou Raspberry Pi + NFC + écran. Vrai système cyber-physique.

À choisir (D3)

Messagerie IoT

MQTT (type Mosquitto) : pub/sub léger pour objets contraints.

À faire

Kafka et oneM2M

Découpler les événements ; décrire les bornes selon un standard.

CI/CD et qualité

GitHub Actions, GitLab CI (runner IUT), SonarQube, DockerHub, Azure.
